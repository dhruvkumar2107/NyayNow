06
Security Infrastructure
Multi-layer security protecting the platform and user data
🔑
JWT Authentication
Stateless signed tokens (jsonwebtoken 9.0.3). Tokens verified on every protected API call.
🔒
Password Hashing
bcryptjs with salted hashing. Plain-text passwords never stored or logged.
🛡️
HTTP Security Headers
Helmet.js enforces CSP, HSTS (1yr + preload), XSS protection, and CORS policy.
🚦
Rate Limiting
Global: 300 req/15min · Auth: 10 attempts/hr · AI: 50 req/15min. Prevents brute-force & DDoS.
🌐
CORS Whitelist
Strict origin whitelist: nyaynow.in, www.nyaynow.in, localhost only. All others rejected.
🛰️
Error Sanitization
Sentry strips passwords & tokens before logging. No sensitive data in error reports.
🔐
WebSocket Auth
Socket.io enforces JWT handshake middleware. Unauthenticated connections are rejected.
📋
DPDP Compliance
India's Digital Personal Data Protection Act 2023. DPDP-compliant privacy policy and data handling.
