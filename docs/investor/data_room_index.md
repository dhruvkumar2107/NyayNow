# Data-room index and evidence owners

| Folder / artifact | Evidence required | Status / owner |
|---|---|---|
| Corporate | incorporation, cap table, IP assignment, tax/GST, board approvals | [NEEDED] |

| Technical | threat model, access controls, incident response, processor list, security review | [NEEDED] |
| Evaluation | dataset permissions, protocol, expert rubrics, baseline results, error log | Not yet run; [NEEDED] |
| Customers | signed pilot letters, consent, usage extracts, outcomes, references | [NEEDED] |
| Financial | bank/ledger reconciliation, revenue cohorts, costs, budget, 18-month model | [NEEDED] |
| Funding | applications, eligibility determinations, grants, investor pipeline | [NEEDED] |
| Legal/privacy | counsel review of product, DPDP obligations, terms, grievance process | [NEEDED] |

Do not place real case files or personal data in the data room without consent, minimization, access controls, and a documented retention basis.
