## Release gate

Do not represent the company as having validated legal accuracy, proprietary foundation models, a licensed comprehensive corpus, verified lawyer supply, security certification, production proof receipts, revenue, customer impact, or committed funding unless the data room contains current, reviewable evidence. Legal, privacy, commercial, and investor-facing copy require qualified human review.
