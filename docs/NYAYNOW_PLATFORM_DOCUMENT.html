Security Infrastructure

06
Technical mitigation measures protecting operations.
JWT Authentication
Stateless authorization signatures (jsonwebtoken version 9.0.3). Extracted and validated on every middleware request.
Password Encryption
Salting and hashing via bcryptjs. Raw strings are scrubbed before arriving at storage or logs.
Helmet.js Protection
Configures HTTP headers preventing clickjacking, enforcing content security policies, and upgrading connections to HTTPS.
Rate Limiting
Standard Express middleware limiting general endpoints to 300 requests per 15 minutes, auth to 10 per hour.
DPDP Compliance
Aligns storage lifetimes and cookie usage patterns to the guidelines of the Indian DPDP Act 2023.
WebSocket Guard
Enforces identical JWT assertions during the initial HTTP handshake of any WebSocket client request.
